 # Airline Flight Price Analysis Dashboard ✈️📊

An end-to-end interactive Business Intelligence dashboard built in Power BI to analyze global aviation trends, pricing patterns, and route dynamics.

## 🚀 Project Overview
This project visualizes flight ticket pricing behavior, airline performance, and passenger preferences. It features a custom dark-themed UI designed for executive presentation and in-depth data exploration.

---

## 📌 Key Dashboard Features & Metrics
* **Executive KPI Cards:** Tracks Total Flights (300K), Average Ticket Price ($208.9K), Max/Min Ticket Prices, and Average Flight Duration with YoY growth indicators[cite: 6].
* **Airline & Route Analysis:** Evaluates market share by airline (e.g., Delta leading total flights) and maps out top source and destination cities (such as New York and London)[cite: 6].
* **Class & Fare Distribution:** Utilizes advanced donut and column charts to break down pricing and volume across Economy, Business, and First Class[cite: 6].
* **Interactive Filtering Sidebar:** Implements custom slicers for seamless data slicing by Airline, Class, Destination City, Departure Time, and Stops[cite: 6].
* **Key Takeaways Footer:** Highlights core business insights and actionable findings directly on the dashboard[cite: 6].
