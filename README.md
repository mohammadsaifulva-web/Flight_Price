Airline Flight Price Analysis Dashboard ✈️📊An end-to-end interactive Business Intelligence dashboard built in Power BI to analyze global aviation trends, pricing patterns, and route dynamics.🚀 Project OverviewThis project visualizes flight ticket pricing behavior, airline performance, and passenger preferences. It features a custom dark-themed UI designed for executive presentation and in-depth data exploration.📌 Key Dashboard Features & MetricsExecutive KPI Cards: Tracks Total Flights (300K), Average Ticket Price ($208.9K), Max/Min Ticket Prices, and Average Flight Duration with YoY growth indicators.   Airline & Route Analysis: Evaluates market share by airline (e.g., Delta leading total flights) and maps out top source and destination cities (such as New York and London).   Class & Fare Distribution: Utilizes advanced donut and column charts to break down pricing and volume across Economy, Business, and First Class.   Interactive Filtering Sidebar: Implements custom slicers for seamless data slicing by Airline, Class, Destination City, Departure Time, and Stops.   Key Takeaways Footer: Highlights core business insights and actionable findings directly on the dashboard.   🛠️ Tech Stack & Tools UsedData Visualization: Power BI (DAX, Data Modeling, Custom Dark Theme Styling)Data Processing & Querying: Python, Pandas, SQL (DBeaver)Version Control & Hosting: GitHub & GitHub Pages📂 Repository StructurePlaintext├── Dataset/             # Cleaned CSV/Excel datasets used for the analysis
